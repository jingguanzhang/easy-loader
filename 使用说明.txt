打开方式
1. 解压完整程序包。两个 HTML、vendor 与 icons 必须保持同级。
2. 打开「装箱排程_经典桌面版.html」，建议现代 Chrome / Edge。
3. 也可将完整目录放到本地或站点服务访问。不依赖 CDN，不需外网。
4. 平台单文件预览无法加载旁边的公共库；请使用实时预览，或下载完整包再解压。
5. 默认进入第一步。空白新方案不自动载入示例或计算；已有草稿仅恢复数据，不恢复上次页签。

编辑器强化：指针缩放、清单收起、移动防穿模与一键修正（v4.6）
- 3D 视图滚轮缩放以鼠标指针为原点，指哪里缩哪里；偏离中心的缩放几乎不漂移，正交视图同样生效。缩放范围受限（透视距离 20-90000 mm，正交倍率 0.05-120），防止缩飞。
- 「逐件装配清单」可以收起，且默认收起为一条标题行；点标题按钮开合。点校验问题定位到清单条目时会自动展开。全选、取消选择按钮在展开的清单标题内。
- 移动物品严格限制穿模：鼠标拖动、方向键、多选、坐标输入、上移/下移一层统一在路径上检测碰撞。被其他货物阻挡时停在接触边界并可沿可通行方向滑行，不会把货物推进彼此内部；越出安全运动区仍按 v4.5 的冗余规则夹紧并提示。触碰贴合不被误判为碰撞。
- 「上移一层 / 下移一层」现在先尝试竖直移动；落点本身悬空、被压或违反货物限制时回退，并在目标高度自动寻找最近的真实货物顶面侧移上架。完全不可行时保持原位，并说明实际原因（如必须置底、碰撞或无支撑）。
- 新增「一键修正」：自动修复悬空、越界、碰撞、叠放违规等问题。修正只移动有问题的单件，其余单件的位置、朝向、托盘参数和货物限制一律不动。无法完全修复时（例如托盘承载超重、库存不足、货物属性冲突），布局原样保留，并明确提示原因，不留半成品。
- 修正与混排一样在后台 Worker 中运行，可随时取消；修正结果是普通未保存编辑，可撤销/重做，仍需通过保存校验后参与装箱。

逐托编辑与复用（v4.8）
- 打托编辑器顶部新增「复用一托 / 摆完为止」按钮（位于“相同组合托数”右侧），与第三步卡片上的复用共用同一套库存核算。
- 第 1 托为模板；用 ◀ ▶ 切换第 2..N 托后，对当前托的任何加入、移动、删除、排布都会把该托物化为单独布局（显示“已单独调整”徽标），适合往各托空隙补放零碎货物；「恢复模板」随时回到模板布局，可撤销。
- 加入组合只消耗当前托的货源，不再强制每托预留一件；库存按全部托实际用量合计预留，解决复用后“托盘上方明明还有空间却无法添加其他货品”的问题。
- 编辑器选择高亮强化：选中件不透明并泛蓝色自发光、描边加深；未选中件压暗，一眼可辨。

整托堆叠（v4.7 载重路径完整支撑）
- JS 校验及求解器都读取第二步的「不可堆叠」；其上方重叠范围内禁止其他货物，即使没有直接接触也不允许跨高桥接。
- 柜内允许整托叠放：下层托内无不可堆叠货物，且上托按「载重路径完整支撑」校验——上托每一件货物的底面必须被同一高度的真实货物顶面完整覆盖；托板边缘允许悬挑，留边、未铺满或中置货物的现实托盘因此都能正常参与叠放。
- 不允许用外廓包络假装支撑：横跨两种高度顶面的上件、货物下方没有真实顶面的位置仍然不能叠放；散件仍不作承托、也不放在组合顶面。
- 整托互叠仅校验几何载重路径与承载，不评估偏心倾覆；报告中已提示人工复核稳定性并视情绑扎、限位。
- v4.5 曾要求整个托盘矩形被 100% 铺满覆盖，现实中几乎没有托盘能满足，导致叠放从不发生；v4.7 按上述载重路径口径重构了求解器支撑判定，旧结果需手动重新计算。
- 必须置底、单件和支撑链的最多堆叠层数、候选柜尺寸/载重继续有效。上托总重量（包括托盘自重）累计计入下方每层托盘的承载；多托共同支撑时保守按全上托重量校核每个支撑，实际受力仍需复核。
- 散件仍不直接放在组合顶面，整托也不以散件作承托。本次扩展仅开放整托/整托叠放；无底板货堆同样需要完整真实支撑。
- 编辑器增加「上移一层」「下移一层」，PageUp / PageDown 操作相邻实际高度层，Shift 配合这两个键按吸附步长微调。多选保持相对高度。
- 可先调高再平移到支撑位置；临时悬空、碰撞或超盘布局只能保存停用草稿，修正后才能保存参与。不允许通过层级或平移新建不可堆叠/必须置底违规。
- 鼠标拖动、方向键、多选及坐标输入都受到同一个有界运动区域限制。冗余为工作区最大边长的 10%，最少 100 mm、最多 500 mm。
- x/z 从 0 到工作区长宽加冗余，完整单件外廓受限；高度有限时 y 区域为「总高上限 - 托盘厚度 + 冗余」。总高填 0 时使用有限编辑范围（至少 2500 mm，按现有单件最高尺寸适当增加），并非无限拖远。
- 冗余只供暂存/微调，不改变托盘物理尺寸、承载、库存在用量或装箱尺寸。超出实体托盘仍会报边界问题。
- 求解器已实际重编译。旧版本结果快照不会按新规则静默复用：输入、组合和方案可恢复，结果需手动重新计算；仍不自动计算。

组合复用与货物删除（v4.3）
- 第三步原「复制」改为「复用」：沿用当前组合的朝向、坐标及托盘，直接累加原组合的托数，不新增重复行。
- 「复用一托」在货品池满足完整一托时增加 1 托；「摆完为止」按各 SKU 剩余库存可完成的最少整托数增加托数。
- 原参与库存不改写；第三步的「组合预留」自动增加，「剩余散件」与编辑器货品池自动减少，以免重复扣库存。缺件余量继续散装，不组成半托。
- 停用草稿首次复用时，从 0 个参与托开始；复用一托即参与 1 托。若之前全局跳过打托，复用会启用所有已勾选组合，预览已计入其他组合用量。
- 单组合最多 10000 托；达到上限也会停止，并保留余量。
- 删除货物时，会同步清理所有当前组合（包括停用草稿）中的该 SKU 单件；被清空的组合自动移除。
- 未删除物品的朝向和坐标保持不动。删除底件造成的悬空等问题会保留校验提示，需要编辑后才能复用或参与装箱。
- 复用与级联删除均为一次可撤销编辑；取消不会改动。修改后旧结果只标记待更新，不自动重算。

四步流程
1. 货柜设置：多种候选柜、自定义内尺寸与载重、柜型偏好和排布策略。
2. 货物清单：尺寸、重量、库存、六种允许方向、限层、不可堆叠、必须置底、装载顺序。
3. 组合打托（可选）：任意货物按件混合，可直接跳过。本步维护独立组合，不修改原货源库存。
4. 装载结果：实际 WASM 求解，多柜明细、三维与二维视图、配载、未装汇总、中文 PDF。

第四步预览（v4.1）
- 尚未计算时显示「开始计算」提示。进入第四步本身不会自动计算；点击计算装箱或按 F5。
- 计算完成、重新打开结果或切回第四步，默认显示完整装载；左上角注明实际显示件数。
- 完整装载时悬停只突出目标，不再将其余箱体淡化成几乎不可见的空柜。
- 点击步骤或拖动步骤滑条进入逐步装载；「完整装载」立即恢复全部货物。
- 「刷新预览」重新绘制结果并适配视角，不重新求解、不修改输入或库存。
- 视图区暂时无尺寸时恢复后自动补绘；WebGL 中断时自动改为真实数据的二维兼容视图。
- 托盘改用木质面板、横梁、9 支撑块、底梁与四向叉车入口；主预览、编辑器及 PDF 共用结构。
- 图形严格按填写的长、宽、厚度绘制，薄盘不会擅自加厚。叉车孔仅为外观，不开放成可装货空间；自重和承载仍使用填写值，不由木材模型推算。

混合打托编辑器
- 从第三步「新建混合组合」或已有组合「编辑」打开；独立 HTML 嵌入主界面。
- 从左侧选货源和件数，加入组合。每一条是一个单件，可分别选择允许方向。
- 左键选中/拖动，Ctrl 多选；吸附步长与边缘吸附可调整。也可在右侧直接输入 x/y/z。
- x 是长向、z 是宽向、y 是高度；y=0 为实体托盘顶面，没有底板时为组合底面。
- 行数沿 z、列数沿 x、层数沿 y，生成规则布局后仍可自由混合修改。
- 支持复制件、删除、旋转、落到支撑面、撤销重做、四视角与适配视图。
- 「自动排布」确实调用 Rust 编译的 arrange_pallet_v4；失败或取消不覆盖旧布局。
- 「保存并参与装载」先做前端几何校验，再调用 WASM 独立校验，主程序再次检查可用库存。
- 「保存草稿」允许保留尚不合法的布局，但该组合不参与装载。可复用合法布局为一托或按货品池摆完为止，托数累加到原组合。
- 取消或关闭编辑器不修改原组合。
- 每组最多 500 件、最多 200 组，相同组合可设置 1–10000 托；超过库存会阻止参与装载。

托盘物理与算法规则
- 可以不使用实体托盘，仅作刚性组合；不使用底板时按单件实际包络占位。
- 自定义实体盘长宽、厚度、自重、承载上限；这些真实计入尺寸、柜载重及报告，不是装饰。
- 按每托成员用量 × 托数预留库存，未预留库存按散件装载，已装 + 未装数量守恒。
- 单件方向必须在第二步允许范围内；高处底面必须同高、完整支撑。
- 必须置底可直接放托盘顶面；不可堆叠货物上不能承托其他货物；整个支撑链继承限层。
- 底件必须在其承托上件之前装配，不得违反第二步装载顺序（1 最先、0 自动）。整托进柜按组内最早成员的优先级；不会把同一整托拆开与散件穿插装载。
- 整托保持竖直，仅允许 0° 或水平 90°；90° 后所有单件方向仍必须允许。
- 整托采用刚性外廓占位，但仅以真实货物顶面校核整托间的完整支撑；不可堆叠、置底、限层、承载和柜高/载重仍有效。不在整托顶面承托散件。
- 实际碰撞、支撑、载重、库存及朝向由 WASM v4 再检查。求解为启发式可行方案，不保证全局最优。
- 几何重心仅作辅助，不等同于实际承压与稳定性认证；绑扎、承压、重心、现场安全与运输法规需人工复核。

输出与数据
- 货物 Excel / XLS / CSV 导入，Excel 导出保留全部原货源字段。旧单品打托字段仅为兼容迁移。
- 完整的混合组合（逐件坐标/方向/托盘/托数）保存在方案、草稿与 JSON 备份中；请用 JSON 迁移组合。
- 旧 JSON 的单品打托会迁移为无底板规则组合；旧 Excel 中的单品打托字段也自动迁移为第三步无底板组合，不在第二步提供旧子选项。
- 结果逐件还原原 SKU，底板独立绘制；装载步骤按整托为一次操作，不拆成散件步骤。
- PDF 包含中文货物汇总、未装数量、安全说明、含底板整托明细与逐件装配表、全装图及步骤图。
- 数据保存在本机浏览器（原 3d_pack_plans 方案库与草稿）或导出文件，不上传到服务器。
- file:// 下 WASM 在 Blob Worker 计算，PDF 自动使用兼容模式；禁用 WebGL 时可用实际位置二维预览。

托盘组合编辑器.html       按件混合打托编辑器（由主程序内嵌；不单独持有货源）
vendor/                  Vue、Three.js、OrbitControls、SheetJS、jsPDF、AutoTable、PDF.js 公共库
icons/                   你自行提供的 PNG 图标；本包不生成替代图片
图标清单.md              33 个 PNG 文件；六种装载方向不需提供 PNG

主业务仍集中在一个 HTML，编辑器按本次允许独立为 HTML；没有另拆 app.js/CSS/业务 Worker 文件。
公共库没有内嵌 HTML，也没有用 Base64 隐藏副本，全部为同级本地 vendor 引用。
只有装载方向恢复真实比例 SVG；其余界面图标保持 icons/xxx.png。缺失 PNG 留空，不影响文字操作。

快捷键
主程序：F5 计算，Ctrl+S 保存，Ctrl+N 新建，Ctrl+O 导入，Ctrl+Z/Y 撤销/重做，Alt+1/2/3/4 切步骤，F1 帮助。
编辑器：F5 自动排布，Ctrl+S 保存并参与，Ctrl+Shift+S 保存停用草稿，Ctrl+Z/Y 撤销/重做，Ctrl+A 多选，Ctrl+D 复制件，方向键平移，PageUp/Down 升降一层，Shift 微调高度，R 旋转，Delete 删除，Esc 取消。

版本
界面修复 v4.1；求解器仍为与上一版字节相同的 EMS v4 mixed-pallet，Rust / wasm-bindgen 实际编译；Vue 3.4.21，Three.js r147 / 匹配的 OrbitControls，原项目 SheetJS、jsPDF、AutoTable，配套 PDF.js 5.4.296。
第三方版权和许可保留在公共库脚本中。原程序下载解压目录未修改。
